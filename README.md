# Flex Stocks

A staged ledger for House Sentinel. One book, a lot of lines, and a denomination that stays quiet until you ask.

The published book is [soham-fliight.github.io/flex-stocks](https://soham-fliight.github.io/flex-stocks/). A push to `main` builds a static export and deploys it with GitHub Pages, the same way as Folio.

## Run it

```bash
npm install
npm test
npm run build
```

Open `index.html`, or the copy written to `out/` when `GITHUB_PAGES=true`.
